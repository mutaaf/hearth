What's private

The TVs and their pairing keys were locked on the sender's phone before anything left it. Hearth's server holds only that scrambled copy, and the key to open it is the part of this link after the #, which browsers never send to any server. The copy is deleted when Hearth opens it, or after 24 hours. Whoever opens the link can use those TVs, so keep it in the family. This page loads no analytics.
